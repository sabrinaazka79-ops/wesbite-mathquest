# MathQuest

Tampilan awal + login MathQuest (Kelas 8).

## Isi
- `index.html` – halaman utama
- `assets/mascot.png` – maskot yang dipakai di halaman
- `assets/logo-asli.png` – logo asli ukuran penuh

## Deploy
1. Upload semua isi folder ini ke repository GitHub (index.html harus di root).
2. Di Netlify: Add new site > Import from Git > pilih repository.
3. Build command: kosongkan. Publish directory: `/` (atau kosongkan). Klik Deploy.
